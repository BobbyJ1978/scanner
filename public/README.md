# 🚀 SMC Analyzer - داشبورد تحلیل هوشمند ارز دیجیتال

## ترکیب Dow Theory + Smart Money Concepts (SMC)

این برنامه یک داشبورد حرفه‌ای تحلیل بازار ارزهای دیجیتال است که با استفاده از تکنیک‌های Dow Theory و Smart Money Concepts، ۱۰ ارز مستعد رشد در ۷ روز آینده را شناسایی می‌کند.

---

## 📋 امکانات

### 🔍 تحلیل بازار
- **Dow Theory**: شناسایی روند از طریق Higher Highs/Lows
- **Smart Money Concepts**: Order Blocks, Fair Value Gaps, Break of Structure, Liquidity Zones
- **واچ‌لیست هوشمند**: ۱۰ ارز برتر با بالاترین امتیاز تحلیل

### 🔔 سیستم اطلاع‌رسانی
- **نوتیفیکیشن مرورگر**: اعلان مستقیم در مرورگر
- **ایمیل**: ارسال آلارم از طریق SMTP
- **تلگرام**: ارسال پیام به کانال/گروه
- **دیسکورد**: ارسال به وبهوک
- **توییتر/X**: انتشار خودکار

### ⚙️ تنظیمات
- آلارم قیمتی سفارشی
- تنظیمات API اختصاصی
- پیکربندی نوتیفیکیشن‌ها

---

## 🛠️ نصب و اجرا

### روش آسان (Windows):
```
1. فایل Run.bat را اجرا کنید
2. صبر کنید تا نصب و بیلد انجام شود
3. مرورگر به صورت خودکار باز می‌شود
```

### روش دستی:
```bash
# نصب ملزومات
npm install

# بیلد فرانت‌اند
npm run build

# نصب سرور
cd server && npm install && cd ..

# اجرای سرور
cd server && node server.js
```
