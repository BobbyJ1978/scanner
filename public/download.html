🚀 SMC Analyzer - کدهای کامل پروژه

📋 راهنما: تمام فایل‌های پروژه در زیر نمایش داده شده‌اند. می‌توانید هر فایل را کپی کرده و در سیستم خود ذخیره کنید.

⚡ روش سریع: دکمه «دانلود همه فایل‌ها» در پایین صفحه را بزنید تا یک فایل HTML دریافت کنید که با اجرای آن، تمام فایل‌ها به صورت خودکار ساخته می‌شوند.

📝 مراحل نصب و اجرا:

  1. Node.js نسخه 18+ را از nodejs.org دانلود و نصب کنید
  2. تمام فایل‌های بالا را در یک پوشه جدید ذخیره کنید (ساختار پوشه‌ها را رعایت کنید)
  3. در Command Prompt به پوشه پروژه بروید
  4. دستور npm install را اجرا کنید
  5. دستور npm run build را اجرا کنید
  6. به پوشه server بروید و npm install و سپس node server.js را اجرا کنید
  7. مرورگر را باز کنید: http://localhost:3000

💡 یا ساده‌تر: فایل Run.bat را در پوشه public اجرا کنید تا همه مراحل خودکار انجام شود.
